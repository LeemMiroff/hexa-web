# Минималистичные ассеты

Геометрия построена программно в SVG, затем экспортирована в PNG. Перерисовка: `node scripts/export-minimal-assets.mjs` из каталога прототипа. Для экспорта нужен sharp; скрипт также поддерживает установленную среду Codex.

## Плитка

`hex-neutral-rounded-64.svg` → `hex-neutral-rounded-64.png`, 64×64, RGBA, около 1,3 КБ.

Правильный шестиугольник без проекции: радиус до исходных вершин 32; шесть одинаковых сторон длиной 32; высота верхней грани 32√3. Скругления — настоящие круговые дуги радиусом 6. Боковина: 6,8595 px, ровно 80% прежних 8,5744 px. Цвет верхней грани #FFFFFF; нижняя боковина #B8B8B8, левая и правая #949494. Для PixiJS можно окрашивать всю текстуру через `sprite.tint`, и боковина останется более тёмной.

После уменьшения толщины геометрия симметрично центрируется в прежнем квадратном холсте. Верхняя грань не растягивается, чтобы заполнить высоту холста. Прозрачность вокруг силуэта сохранена.

## Поле

`board-minimal.svg` — исходник, логическая область 448×500.

| PNG | Разрешение | Размер файла | Применение |
| --- | --- | --- | --- |
| `board-minimal@2x.png` | 896×1000 | около 41 КБ | Основной вариант для поля шириной 350–430 CSS px |
| `board-minimal@3x.png` | 1344×1500 | около 66 КБ | Более плотные дисплеи / увеличенное поле |

Размеры не обязаны быть степенями двойки. При загрузке одной версии расход памяти декодированной RGBA-текстуры примерно 3,4 МиБ для 2x и 7,7 МиБ для 3x, без учёта служебных расходов рендера. Обе версии загружать одновременно не требуется.

Поле содержит 61 клетку радиуса 4. Положение центров задаётся axial-координатами:

```
x = 224 + 48q
y = 250 + 32√3(r + q/2)
```

Функция вычисления координат импортирована из `src/model.mjs`. Все центры проверяются обратным преобразованием. Сетка имеет равномерный геометрический зазор 1,25 логического px между прямыми гранями. Три очень близких оттенка: #2B2538, #2D273A, #292335. Рекомендуемый фон: #231E32. Снаружи и между сотами — прозрачность. Нет рамки, общего основания, обводок или углублений.

## Совмещение с фигурами

Полный набор координат, размеры, точка привязки и коэффициенты лежат в `minimal-geometry.json`. Для PNG-плитки точка привязки находится в центре ВЕРХНЕЙ грани, а не в центре всего изображения с боковиной:

```js
tile.anchor.set(0.5, 0.4464101615);
tile.width = tile.height = geometry.placement.spriteLogicalWidth;
tile.position.set(cell.x, cell.y);
```

Точные значения следует брать из JSON. Такой размер соответствует чуть уменьшенным сотам поля с швом. Поле и слой плиток масштабируются одним родительским контейнером, равномерно по обеим осям. Числа/значения плиток остаются отдельным текстовым слоем.

В игровом экране подключены `board-minimal@2x.png`, `hex-neutral-rounded-64.png` и этот JSON с координатами. Размер поля и точка привязки плиток вычисляются из общих параметров при изменении экрана. Прежние ассеты сохранены как история первоначального оформления.

Игровой экран использует три готовые градиентные PNG 64×64: hex-red-gradient-64.png, hex-yellow-gradient-64.png, hex-blue-gradient-64.png. SVG-источники находятся в concepts/gradient-tiles. Цвет выбирается текстурой без дополнительного tint; слой анимаций использует те же PNG. Геометрия и привязки прежние.

Текущая версия плиток: hex-red-flow-64.png, hex-yellow-flow-64.png, hex-blue-flow-64.png, по 64×64. Выбран второй подход «Перетекание оттенков». SVG-источники: concepts/gradient-tiles/expressive-approaches/hex-*-flow-64.svg.

Текущая версия плиток: hex-red-cloud-64.png, hex-yellow-cloud-64.png, hex-blue-cloud-64.png, по 64×64. Выбран третий подход «Цветовое облако». SVG-источники: concepts/gradient-tiles/expressive-approaches/hex-*-cloud-64.svg.

Для чёткости на плотных дисплеях подключены hex-red-cloud-256.png, hex-yellow-cloud-256.png, hex-blue-cloud-256.png. Экспорт непосредственно из SVG с density 288 (4×). Геометрические размеры и anchor остаются логическими 64×64; отображаемый размер задаётся явно. Canvas-слой использует те же текстуры. Суммарная RGBA-память трёх текстур: 768 КиБ без mipmaps.

Геометрический зазор уменьшен вдвое: 1,25 логического px вместо 2,5. Центры клеток прежние; размеры сот поля и отображаемых плиток пересчитаны общей геометрией.
